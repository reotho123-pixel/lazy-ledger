# 熊记（记账）

一个离线可用的记账小应用，可以添加到 iPhone 主屏幕当 App 用。

- **自动记账**：配合 iPhone「快捷指令」，截屏微信/支付宝账单就能自动记一笔
- **手动记账**：也可以直接在上面输入，比如「午饭15块」
- **统计**：分类占比、每月对比、每日支出、预算进度
- **离线可用**：断网也能用，联网后自动同步
- **数据是自己的**：账目存在你自己的 GitHub **私有**仓库里，本页面不含任何人的账单数据

## 怎么用（第一次）

1. 用 iPhone Safari 打开本页
2. 点「分享」→「添加到主屏幕」，以后像 App 一样打开
3. 进「我的」→「GitHub 同步」，填三样东西：
   - GitHub 用户名
   - 仓库名（自己的私有仓库，例如 `lazy-ledger-friend`）
   - Token（只授权这一个仓库的细粒度 token，权限选 **Contents: Read and write**）
4. 以后每次记账都会自动同步到那个仓库

> Token 只保存在这台设备的浏览器里，不会上传到任何地方。

## 关于隐私

网页本身是公开的，但**只有代码、没有数据**。你的账单只存在：

- 这台手机浏览器的本地缓存
- 你自己的 GitHub 私有仓库

别人打开同一个网址，看到的是一个空账本。
