# 懒人记账 Lazy Ledger

iPhone 快捷指令自动记账 + 手动记账 + 统计的纯前端 PWA。参考 B 站视频
《iPhone懒人记账 自动记账 究极不掺水教程来啦》（BV1pg4y1e7oZ）的「快捷指令 → 飞书多维表格」方案，
把云端的飞书换成了 **你自己的 GitHub 仓库**：快捷指令通过 GitHub API 把每笔账写成一个 JSON 文件，
本应用从仓库读取并展示，离线也能正常使用。

**在线使用**：https://reotho123-pixel.github.io/lazy-ledger/

## 它是怎么工作的（对照飞书方案）

| B 站视频里的飞书方案 | 本应用 |
|---|---|
| 飞书多维表格 | 仓库 `data/` 目录，每笔账一个 `rec-*.json` |
| 飞书机器人 / 开放平台 API | GitHub Contents API（PUT/DELETE） |
| 飞书 App 里看账单 | 本 PWA（可加到 iPhone 主屏幕，离线可用） |

账单记录格式（`raw` 是截图识别出来的全文，只用于自动判分类，不在界面显示）：

```json
{"id":"rec-2026-10-06_18-30","type":"expense","amount":25.5,"category":"餐饮","note":"午饭","account":"微信支付","time":"2026-10-06_18-30","src":"shortcut","raw":"微信支付 付款成功 兰州拉面 ¥25.50"}
```

## 搭配 iPhone 快捷指令（自动记账）

### 第 0 步：创建 Token

1. 打开 https://github.com/settings/personal-access-tokens/new
2. 名称随意，过期时间选最长；**仓库访问 → 仅选择仓库 → lazy-ledger**
3. 权限：Repository permissions → **Contents → Read and write**
4. 生成并复制 token（经典 token 勾选 `repo` scope 也可以）

### 第 1 步：配置本应用

在网页 App「设置」页填入 GitHub 用户名 / 仓库名 / Token → 点「保存并测试连接」。

### 第 2 步：截屏识别版快捷指令（已实测跑通）

iOS 27 实际可用的动作序列，按顺序搭：

1. **截屏**（系统自带，会自动截当前屏幕）
2. **从截屏提取文本** → 得到「提取的文本」
3. **匹配文本**：正则 `[-¥]\s*[0-9,]+\.[0-9]{1,2}|\d+(\.\d+)?元` → 取第 1 组为「更新后的文本」（金额）
4. **格式化日期**（当前日期，自定义格式 `yyyy-MM-dd_HH-mm`）→ 变量名建议改成「时间」，别叫「日期」
5. **如果 / 否则**：判断提取的文本里含「微信」→ 支付方式「微信支付」，否则「支付宝」
6. **文本**：拼出下面这行 JSON（尖括号里的换成上面变量的蓝色小块）

   ```
   {"id":"rec-<时间>","type":"expense","amount":<更新后的文本>,"category":"其他","note":"","account":"<支付方式>","time":"<时间>","src":"shortcut","raw":"<提取的文本>"}
   ```

   - 必须用**英文冒号 `:`**，中文全角「：」会让 JSON 失效、记录被 App 静默跳过
   - 变量小块前后**不要留空格**，否则文件名带尾随空格
   - **`raw` 里的换行必须去掉**：OCR 文本是多行的，直接塞进去会让 JSON 非法。在「文本」动作
     **之前**加一步「替换文本」，把 `raw` 的换行替换成空格（正则 `\n` 或直接替换"换行符"），
     或者把这一步放在第 8 步去 Base64 换行之前。App 有兜底能自动救回，但别依赖它。
   - `raw` 是识别出的全文，App 用它自动判分类（见下）
7. **Base64 编码** → 上一步文本
8. **替换文本**：正则 `[^A-Za-z0-9+/=]` → 空（去掉 Base64 里的换行，否则 GitHub 报 422）
9. **获取 URL 内容**（方法 PUT）：
   - URL `https://api.github.com/repos/<用户名>/lazy-ledger/contents/data/rec-<时间>.json`
   - Headers：`Authorization: Bearer <Token>`、`Accept: application/vnd.github+json`
   - 请求体：`{"message":"ledger","content":"<第8步结果>"}`

**日常用法**：付完款停在支付成功页 → 点右下角「分享」→「运行快捷指令」（或先轻点背面两下再分享）。
建议在 设置 → 辅助功能 → 触控 → 轻点背面 绑定这个快捷指令，付款后连点两下背面即可记账。

### 第 3 步：自动分类（v1.4）

**不要在快捷指令里放分类菜单/列表。** iOS 27 的「从菜单中选取」「从列表中选取」输出变量会错绑成
最前面的日期值（改名、重建、换绑定都无效），写进去的分类会变成 `2026-10-07_01-40` 这种日期串。

正确做法是分类交给 App：快捷指令只在 JSON 里多传一个 `raw`（截屏识别出的全文），App 按关键词自动判断
（餐饮 / 交通 / 购物 / 日用 / 居住 / 通讯 / 医疗 / 学习 / 娱乐 / 人情，工资 / 兼职 / 理财 / 红包 / 报销）。

- 明细里自动判出来的分类会带一个紫色「自动」标签，方便和手动改的区分
- 判错了就点开那条记录改分类 —— 改过的会打上标记，以后不会被重跑规则覆盖
- 设置 → 数据 → 「🔁 重新识别分类」可以对全部「其他」批量重判一遍
- **云端已有的坏记录会自愈**：同步拉到分类是日期串/整段列表、或 JSON 本身损坏（如 `"amount":,`）的记录时，
  App 会自动修正并把修好的版本推回仓库，不需要手动处理

### 排查

- 401：token 错误；404：用户名/仓库名错误；403：权限不足（检查 Contents 权限）
- 422：Base64 里带了换行，检查第 8 步的替换文本
- 记录没出现：多半是 JSON 里用了中文全角冒号、变量前后有空格，或 `raw` 里的换行没去掉
- **分类变成日期**（如 `2026-10-07_01-40`）：快捷指令里放了菜单/列表，删掉它，改用 `raw` 自动分类
- 文件名不要用 `yyyy-MM-dd HH:mm`（空格和冒号在 URL 里非法），必须用 `yyyy-MM-dd_HH-mm`

## 本地数据与隐私

- 所有数据保存在本机浏览器（localStorage）+ 你自己的 GitHub 仓库，没有任何第三方服务器
- Token 只存在本机浏览器，建议使用仅授权 `lazy-ledger` 一个仓库的 fine-grained token

## 本地开发

无 node/git 环境，用仓库内 `tools/server.ps1` 起 TCP 静态服务器（127.0.0.1:8765），
`tools/deploy.ps1` 通过 GitHub REST API 部署（token 从环境变量 `GH_TOKEN` 读取，绝不写盘）。
改动代码后记得把 `sw.js` 里的 `CACHE` 版本号 +1 再部署。

**一键部署（推荐）**：双击 `tools\deploy-now.bat`，按提示粘贴 token 即可。
token 在安全输入框里输入（不回显），只在内存里用一次，不写进任何文件。

**命令行部署**：先在当前会话设置 token（不写盘），再跑脚本：

```powershell
$env:GH_TOKEN = "ghp_…"
powershell -NoProfile -ExecutionPolicy Bypass -File tools\deploy.ps1
```
