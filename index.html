🎁 分享给朋友
把这个网页发给朋友，他们打开就是全新的空白账本，看不到你的任何记录。
数据存在两个地方：朋友自己的手机浏览器 + 朋友自己的 GitHub 仓库。 跟你的完全隔离，互相看不到。
朋友要做什么才能自动记账？
  1. 打开这个网址 → 添加到主屏幕（Safari 分享 → 添加到主屏幕），之后就能离线用
  2. 自己建一个 GitHub 仓库（例如也叫 lazy-ledger）
  3. 自己生成一个 token（只授权那一个仓库的 Contents 读写权限）
  4. 在 App「设置」里填：自己的用户名 / 仓库名 / token → 保存并测试连接
  5. 照着「📱 快捷指令速查」搭一遍快捷指令（把里面的用户名换成自己的）

⚠️ 千万不要把你的 token 给别人 —— 那等于把仓库钥匙给出去。每个人用自己的。

📱 快捷指令速查
已搭好的「记一笔」参数速查；完整搭建教程见仓库 README。
上传接口 / 金额正则 / 记录 JSON

上传（PUT，头部带 Bearer token）：

https://api.github.com/repos/你的用户名/lazy-ledger/contents/data/rec-日期.json

金额正则：

[-¥]\s*[0-9,]+\.[0-9]{1,2}|\d+(\.[0-9]+)?元

记录 JSON：

{"id":"rec-[格式化后的日期]","type":"expense","amount":[更新后的文本],"category":"其他","note":"","account":"支付宝","time":"[格式化后的日期]","src":"shortcut","raw":"[从截屏提取文本]"}

v1.4：raw = 识别出的全文，App 会按关键词自动判分类（餐饮/交通/购物…），判出来的后面会带紫色「自动」标签，判不准就点开记录手动改。快捷指令里不要再放分类菜单/列表（iOS 27 会把它的输出错绑成日期）。

⚠️ 422 = Base64 带了换行（检查去换行的替换文本）；JSON 里必须用英文冒号 :；金额变量前后别留空格。

日常使用 / 报错对照
  1. 付完款停在支付成功页 → 轻点背面两下（设置→辅助功能→触控→轻点背面绑定）→ 点选金额
  2. 分类由 App 按识别文字自动判，带紫色「自动」标签；点开记录可改，改过的不会被重跑覆盖
  3. 401=token 错；404=仓库/权限错；422=Base64 或 JSON 不合法
