📱 快捷指令配置教程
和 B 站《iPhone懒人记账》飞书方案同款思路：快捷指令解析支付信息 → 写入云端表格；这里把"飞书多维表格"换成"你自己的 GitHub 仓库 + 本应用"。
① 准备：创建 GitHub Token
  1. 电脑或手机打开 github.com/settings/personal-access-tokens/new
  2. 名称随意（如 lazy-ledger），过期时间选最长
  3. 仓库访问 → 仅选择仓库 → lazy-ledger
  4. 权限 → Repository permissions → Contents 设为 Read and write
  5. 生成后复制 token（ghp_ 开头的是经典 token，勾选 repo 权限也可以）
② 配置本应用同步
  1. 在上方填入 用户名 / 仓库名 / Token
  2. 点「保存并测试连接」，提示成功即可
  3. 以后每笔记录（手动 + 快捷指令）都会自动双向同步
③ 手动快速记账快捷指令（推荐先做这个）

打开 快捷指令 App → ＋ 新建，按顺序添加这些动作：

  1. 询问输入：提示"金额"，输入类型选数字
  2. 从列表中选取：列表填 餐饮,交通,购物,日用,居住,娱乐,医疗,学习,人情,其他，提示"分类"
  3. 格式化日期：当前日期，格式自定义 yyyy-MM-dd HH:mm → 用于"时间"
  4. 格式化日期：当前日期，格式自定义 yyyyMMdd-HHmmss → 用于文件名
  5. 文本：粘贴下面模板，把 金额 换成"询问输入"的变量、分类 换成"选取"的变量、时间 换成第3步变量、文件名 换成第4步变量
  6. Base64 编码：编码上一步的文本
  7. 获取 URL 内容：
    • URL：https://api.github.com/repos/你的用户名/lazy-ledger/contents/data/rec-文件名.json
    • 方法：PUT
    • Headers：Authorization = Bearer 你的Token；Accept = application/vnd.github+json
    • 请求体（JSON）：{"message":"ledger","content":"Base64结果变量"}
  8. （可选）显示通知："已记账 ✔"
④ 自动记账：支付成功自动上传
  1. 把上面第1步改成：接收通知文本（或"匹配文本"）
  2. 添加 匹配文本：输入=通知文本，正则 ¥\s*([0-9]+(?:\.[0-9]+)?)，取第1组作为金额
  3. 金额取不到时（比如没有 ¥ 符号）：把正则换成 [0-9]+(?:\.[0-9]+)? 再试，或加一个"如果…否则"手动输入兜底
  4. 自动化入口：快捷指令 → 自动化 → ＋ → App → 选 支付宝/微信 → 勾"通知" → 立即运行、不询问 → 运行上面的快捷指令
  5. 微信提示：部分微信支付通知不带金额，可在"支付成功"页面点 分享 → 运行快捷指令，或轻点背面手动记
  6. iOS 17+：也可以把自动化触发设为"轻点 iPhone 背面两下"，秒变手动速记
⑤ 验证 & 常见问题
  1. 运行快捷指令 → 回到本页点「立即同步」→ 明细里出现记录即成功
  2. 上传失败先检查：token 是否复制全、仓库是否选对、Contents 权限是否为 Read and write
  3. 快捷指令里如果提示 401 = token 错；404 = 用户名/仓库名错
  4. 快捷指令记录默认分类"其他"，可在本 App 点开记录随时修改
数据
本地数据仅保存在本设备浏览器；配置同步后，云端数据在你的 GitHub 仓库 data/ 目录，完全归你所有。
